🔧 Next Steps:

1. Create an OAuth2 client:

   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "auth-server.hydraAdmin.fullname" . }} 4445:4445

   curl -X POST http://localhost:4445/admin/clients \
     -H "Content-Type: application/json" \
     -d '{
       "client_id": "my-client",
       "client_secret": "my-secret",
       "grant_types": ["authorization_code", "refresh_token"],
       "redirect_uris": ["http://localhost:5173/callback"],
       "response_types": ["code"],
       "scope": "openid offline_access"
     }'

2. Test the OAuth2 flow by navigating to:
   http://localhost:4444/oauth2/auth?client_id=my-client&response_type=code&scope=openid&redirect_uri=http://localhost:5173/callback
