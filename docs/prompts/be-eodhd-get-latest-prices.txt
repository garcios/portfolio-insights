Suggest a complete strategy for retrieving the latest asset prices from the EODHD API and inserting or updating them in the marketdata.asset_prices table.

Context

https://eodhd.com/api/real-time/AAPL.US?api_token=demo&fmt=json

Requirements
	•	Implement the Golang code in the marketdata-service.
	•	Read from the marketdata.asset_prices table to determine which dates or tickers require updates.
	•	Retrieve the API token from the environment variable EODHD_API_TOKEN.
	•	Make a GET request to:
		https://eodhd.com/api/real-time/{TICKER}.{EXCHANGE}?api_token=${EODHD_API_TOKEN}&fmt=json
	•	Example: AAPL.US → Ticker: AAPL, Exchange: US
	•	Parse the JSON response and insert or update rows in marketdata.asset_prices.
	•	Provide an HTTP endpoint that triggers this job on demand.
	•	Outline any recommended error handling, logging, or retry logic.
